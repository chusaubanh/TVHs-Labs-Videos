## TỔNG QUAN LUỒNG SẢN XUẤT VIDEO CÙNG AI

Thay vì phải mở terminal gõ hàng chục câu lệnh thủ công, quy trình vận hành được tự động hóa trọn gói thông qua công cụ hỗ trợ AI (như Antigravity hoặc Claude Code):

1. **Bước 1:** Chuột phải vào file nén `TVHs-Labs-Video-Setup.zip`, giải nén vào thư mục làm việc và sao chép đường dẫn thư mục vào bộ nhớ tạm.
2. **Bước 2:** Trên giao diện AI, bấm nút `New` để tạo phiên làm việc mới, chọn `Choose environment > Choose a folder to work in` và dán đường dẫn thư mục vừa giải nén.
3. **Bước 3:** Tại khung chat, nhập câu lệnh: *"Đọc toàn bộ hệ thống và cài đặt các dependence cần thiết nhé"*. AI tự động phân tích cấu trúc, cài đặt toàn bộ dependencies trong nền và chạy bài kiểm tra sức khỏe hệ thống đạt chuẩn tích xanh.
4. **Bước 4:** Kéo thả file kịch bản mẫu vào khung chat, chọn các tùy chọn xác nhận rồi bấm `Next` để AI bóc tách câu thoại và mở bảng duyệt kịch bản ở khung bên phải.
5. **Bước 5:** Bấm nghe thử trực tiếp các câu thoại được AI thu âm, sau đó bấm nút thu lại để AI hoàn thiện toàn bộ giọng đọc và xuất bản video thành phẩm.
6. **Mở rộng (Chế độ C):** Dựng từ video người thật nói — AI tự động nhận diện giọng nói bằng WhisperX, lọc sạch tạp âm bằng DeepFilterNet và mở Web Editor trực quan.

## BẢNG TỔNG HỢP CÁC LỆNH HỆ THỐNG TỰ ĐỘNG CHẠY NỀN

Các bạn không cần tự gõ những lệnh này — AI Agent sẽ tự động gọi khi tiếp nhận yêu cầu từ các bạn:

| Tác vụ | Lệnh AI tự chạy nền | Mục đích tự động |
| :--- | :--- | :--- |
| **Cài đặt hệ thống** | `npm run setup` | Cài đặt package Node, tạo môi trường VieNeu và PyTorch CUDA |
| **Kiểm tra sức khỏe** | `npm run doctor` | Kiểm tra Node, FFmpeg, uv, VieNeu và GPU NVIDIA |
| **Máy chủ giọng đọc** | `npm run tts:server` | Khởi động server VieNeu-TTS v3 Turbo tại `127.0.0.1:8124` |
| **Kiểm tra kịch bản** | `npm run script:validate` | Kiểm tra cấu trúc kịch bản và sinh bảng duyệt `script-review.md` |
| **Duyệt kịch bản** | `npm run approve ... script` | Chốt phê duyệt kịch bản để mở khóa bước thu âm |
| **Thu âm tự động** | `npm run voice` | Sinh file âm thanh WAV từng câu thoại từ server TTS |
| **Dựng ảnh duyệt** | `npm run stills` | Chụp các khung hình tiêu biểu để kiểm tra phần nhìn |
| **Duyệt phần nhìn** | `npm run approve ... visual` | Chốt phê duyệt phần nhìn để mở khóa bước render |
| **Xuất bản MP4** | `npm run render` | Kết xuất video hoàn chỉnh với GPU NVENC |
| **Chế độ C clip thật** | `npm run th:setup` & `npm run editor` | Cài môi trường WhisperX và mở giao diện Web Editor |
